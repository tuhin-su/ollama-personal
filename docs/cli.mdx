### Run a model

```
ollama run gemma4
```

### Launch integrations

```
ollama launch
```

Configure and launch external applications to use Ollama models. This provides an interactive way to set up and start integrations with supported apps.

#### Supported integrations

- **OpenCode** - Open-source coding assistant
- **Claude Code** - Anthropic's agentic coding tool
- **Codex** - OpenAI's coding assistant
- **VS Code** - Microsoft's IDE with built-in AI chat
- **Droid** - Factory's AI coding agent

#### Examples

Launch an integration interactively:

```
ollama launch
```

Launch a specific integration:

```
ollama launch claude
```

Launch with a specific model:

```
ollama launch claude --model qwen3.5
```

Configure without launching:

```
ollama launch droid --config
```

#### Multiline input

For multiline input, you can wrap text with `"""`:

```
>>> """Hello,
... world!
... """
I'm a basic program that prints the famous "Hello, world!" message to the console.
```

#### Multimodal models

```
ollama run gemma4 "What's in this image? /Users/jmorgan/Desktop/smile.png"
```

### Generate embeddings

```
ollama run embeddinggemma "Hello world"
```

Output is a JSON array:

```
echo "Hello world" | ollama run nomic-embed-text
```

### Ask a decision model

```
ollama run nimble --ask "Is a refund being requested?" < ticket.txt

ollama run nimble --ask "Which team should handle this?" \
  --choice billing="Payments and refunds" \
  --choice technical="Software problems" < ticket.txt

ollama run nimble --ask "How urgent is this?" \
  --level "Routine" \
  --level "Soon" \
  --level "Immediate" < ticket.txt
```

The state is piped in or given after the model name, as text or JSON. Each `--ask` question is answered yes or no, unless it's followed by labels to choose from (`--choice`) or levels to score it on (`--level`). See [Decision](/capabilities/decision#ask-from-the-terminal).

### Speak with a speech model

```
ollama run phonon "Hello from Ollama."

ollama run phonon --voice Zoey "Hi, this is Zoey."

ollama run phonon "Save this to a file." > speech.wav
```

The audio plays through your speakers, or is written as a WAV file when the output is redirected. Run it without text to speak each line you type. See [Speech](/capabilities/speech#speak-from-the-terminal).

```

```

### List models

```
ollama ls
```

### Export a model as GGUF

Export a model to a `.gguf` file:

```
ollama export gemma4
ollama export gemma4 ./my-model.gguf
```

### Import a GGUF file

Import a `.gguf` file into Ollama under a model name:

```
ollama import my-custom-model ./my-model.gguf
```

### Rename a model

Rename an existing model using its name or model ID:

```
ollama rename old-name new-name
ollama rename d6896264e107 new-name
ollama mv old-name new-name
```

### Deep model inspection (Dev tools)

Inspect model parameters, layers, tensors, quantization breakdown, and GGUF metadata:

```
ollama dev info <model>
ollama dev info <model-id>
```

Filter by specific sections or output in JSON:

```
# Show layer-by-layer architectural breakdown & quantization distribution
ollama dev info gemma4 --layers

# Show detailed tensor table
ollama dev info gemma4 --tensors

# Show all GGUF key-value metadata parameters
ollama dev info gemma4 --metadata

# Show on-disk blob storage and manifest details
ollama dev info gemma4 --storage

# Output all model inspection details as JSON
ollama dev info gemma4 --json
```

### Neural Network Web Visualizer & Passive Listener

Launch a local real-time Web UI visualizer that passively listens for active API inference requests without sending any prompts itself:

```
ollama dev ui
```

Options:
* `--port`, `-p`: Port for the visualizer dashboard and proxy listener (default: `11435`).
* `--target`: Target Ollama server address (default: `http://127.0.0.1:11434`).
* `--no-browser`: Do not automatically open the browser on launch.

To monitor standard requests in real time, simply route your CLI command or client through the listener:

```
OLLAMA_HOST=127.0.0.1:11435 ollama run deepseek-r1-distill-qwen-8b-abliterated.q4_k_m
```

### Create a customized model

First, create a `Modelfile`

```
FROM gemma4
SYSTEM """You are a happy cat."""
```

Then run `ollama create`:

```
ollama create -f Modelfile
```
